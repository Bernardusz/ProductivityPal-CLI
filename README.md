# 📚 ProductivityPal CLI — Python Productivity Assistant

A terminal-based productivity app to help you:
- 📖 Manage notes  
- 📝 Track tasks and deadlines  
- ⏰ Run Pomodoro study sessions  
- 💾 Save & load everything with JSON  

Built with **Python OOP**, **CLI interaction**, and 💪 pure hustle.

---

## 🚀 Features  

✅ Add, view, edit, and delete notes by subject  
✅ Attach formulas (Math/Science) or vocab (Languages)  
✅ Manage tasks with priorities, deadlines, and status  
✅ Sort tasks by priority or completion  
✅ Study with built-in Pomodoro timers (25/5 & 50/10 sessions)  
✅ Save and load your sessions via JSON  
✅ Export notes to `.txt` files  
✅ Modular, clean, and readable OOP structure  

---

## 📁 Project Structure  

```bash
.
├── allfunctions.py      # Core classes: Notes, Tasks, Pomodoro, ProductivityPal manager
├── script.py            # CLI menu and interface
├── welcome.txt          # Welcome screen / CLI command list
└── data.json            # Auto-saved notes, tasks, and logs
```

## 📌 How to Run  

```bash

cd ProductivityPal-CLI
python script.py
```

## 📖 Available Commands  

- `Add Note`
- `See Note`

- `Remove Note`
- `Export Note to TXT`
- `Add Task`
- `See All Tasks`
- `See Task By` (Priority or Incomplete-Finished)
- `Mark Done`
- `Save to JSON`
- `Load from JSON`
- `Study` (Pomodoro 25/5 or 50/10)
- `Exit`
